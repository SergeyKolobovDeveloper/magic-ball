# Project Magic 8 Ball

Інтерактивний веб-додаток Magic 8 Ball, створений з використанням сучасних веб-технологій. Проєкт підтримує динамічні анімації, зміну кольорів залежно від категорії відповіді та асинхронні запити без перезавантаження сторінки (AJAX).

- **Візуалізація кулі:** Стилізоване оформлення за допомогою CSS.
- **Динамічна анімація:** Реалістичне струшування кулі (`@keyframes`) при введенні запитання.
- **AJAX:** Отримання відповідей від сервера «на льоту» без перезавантаження сторінки.
- **Категоризація відповідей:** Випадковий вибір категорій (позитивні, негативні, сумнівні, нейтральні) з плавною зміною кольору віконця кулі.
- **Валідація:** Перевірка введеного тексту на наявність знака питання (`?`).

## Технології
- **Frontend:** HTML5, CSS3 (Flexbox, CSS Animations), JavaScript (ES6+, Fetch API, DOMParser).
- **Backend:** PHP 8+ (розподіл логіки, масиви відповідей, конструкції `match`).
- **Архітектура:** Модульна структура проєкту (`actions/`, `public/`, `includes/`).

magic-ball/
